# 나만의 퀴즈 게임 (고양이 퀴즈)

## 1. 프로젝트 개요
터미널에서 실행하는 콘솔 퀴즈 게임입니다. Python 기본 문법(변수, 조건문, 반복문, 함수)과 클래스(`Quiz`, `QuizGame`)로 코드를 구조화했고, 퀴즈 데이터와 점수는 `state.json` 파일에 저장해 프로그램을 종료했다가 다시 실행해도 그대로 유지됩니다.

## 2. 퀴즈 주제와 선정 이유
주제는 **고양이**입니다. 평소 관심이 많은 소재라 문제를 직접 만들기 쉬웠고, 습성/품종/신체 특징처럼 사실 기반 4지선다 문제를 구성하기에도 적합했습니다. 기본으로 제공되는 고양이 퀴즈는 총 7문제입니다.

## 3. 실행 방법
Python 3.10 이상이 필요하며, 외부 라이브러리 설치 없이 표준 라이브러리만 사용합니다.

```bash
python3 main.py
```

## 4. 기능 목록
- **퀴즈 풀기**: 풀 문제 수를 선택하면 등록된 퀴즈 중 무작위로 그만큼 뽑아 출제합니다. 각 문제에서 `h`를 입력하면 힌트를 볼 수 있으며(힌트를 본 문제는 정답 점수가 절반으로 반영), 다 풀면 정답 수와 최종 점수를 보여주고 최고 점수를 갱신합니다.
- **퀴즈 추가**: 문제, 선택지 4개, 정답 번호(1~4), 힌트(선택)를 입력받아 새 퀴즈를 등록하고 즉시 파일에 저장합니다.
- **퀴즈 목록**: 등록된 모든 퀴즈의 문제만 번호와 함께 보여줍니다.
- **퀴즈 삭제**: 목록에서 번호를 선택해 퀴즈를 삭제하고 파일에 반영합니다.
- **점수 확인**: 최고 점수와 지금까지 플레이한 전체 기록(날짜/시간, 문제 수, 점수)을 보여줍니다.
- **잘못된 입력 처리**: 메뉴 선택과 정답 입력 모두 공백 제거, 숫자 변환 실패, 범위 밖 입력, 빈 입력을 감지해 안내 메시지를 출력하고 재입력을 받습니다.
- **안전 종료**: `Ctrl+C`나 `Ctrl+D`(EOF)로 중단되어도 지금까지 진행 상황을 저장한 뒤 안전하게 종료합니다.
- **손상된 데이터 복구**: `state.json`이 없거나 손상된 경우 기본 고양이 퀴즈 데이터로 자동 초기화합니다.

## 5. 파일 구조
```
Codyssey_E1_2/

├── .gitignore
└── README.md
```

## 6. 데이터 파일 설명 (`state.json`)
- **경로**: 프로젝트 루트(`main.py`와 같은 위치)의 `state.json`, UTF-8로 인코딩됩니다.
- **역할**: 등록된 퀴즈 목록, 최고 점수, 플레이 기록을 저장해 프로그램을 재시작해도 데이터가 유지되게 합니다. 파일이 없으면 `cat_quizzes.py`의 기본 퀴즈로 새로 만들고, 읽는 중 오류가 나면(JSON 파싱 실패 등) 기본 데이터로 복구합니다.
- **스키마**:
```json
{
  "quizzes": [
    {
      "question": "고양이가 하루 평균 자는 시간은 약 몇 시간일까요?",
      "choices": ["8시간", "12시간", "16시간", "20시간"],
      "answer": 3,
      "hint": "고양이는 하루의 3분의 2 가까이를 잠으로 보냅니다."
    }
  ],
  "best_score": 80,
  "history": [
    {
      "datetime": "2026-07-29 18:30:00",
      "total": 5,
      "correct": 4,
      "score": 80
    }
  ]
}
```
  - `quizzes`: 퀴즈 목록. 각 항목은 `question`(문제), `choices`(선택지 4개), `answer`(정답 번호 1~4), `hint`(힌트, 없으면 빈 문자열)
  - `best_score`: 지금까지 기록한 최고 점수(%)
  - `history`: 퀴즈를 풀 때마다 추가되는 기록 (날짜/시간, 출제된 문제 수, 정답 수, 점수)
